# Senior Full-Stack Engineer

We are hiring a Senior Full-Stack Engineer to build and run customer-facing web products end to end.
The team ships a React/TypeScript front end backed by Python services and a PostgreSQL database,
deployed to the cloud with automated CI/CD.

## What you will do

- Design, build and operate features across the whole stack: user interface, APIs, data model and deployment.
- Own a product area: make architecture decisions, review code, and keep it reliable in production (monitoring, on-call, incident follow-up).
- Mentor other engineers and work directly with product and design to turn requirements into shipped software.

## What we look for

- About 4 or more years of professional software engineering experience.
- Production experience on **both** sides of the stack:
  - front end: React with TypeScript, or an equivalent modern framework;
  - back end: services and APIs in Python (Django, FastAPI or Flask) or another server-side language (Node.js, Go, Java, .NET and similar are fine).
- Working knowledge of relational databases, REST or GraphQL APIs, testing, and cloud deployment.
- Evidence of senior scope: owning a system or feature from design to production, leading or mentoring people, or making architecture decisions.
- Clear written English.

## What does not count

- Course, bootcamp or hobby projects in place of production experience.
- Long experience in a different discipline (QA, data analysis, research, project or product management) without production web or service development.

School, employer prestige and personal details are not criteria.
