# Senior Full-Stack Engineer

We are hiring a senior engineer to own features end to end across our web product: a React/TypeScript front end and a Python back end.

## What you will do
- Design, build and ship user-facing features in React and TypeScript, from UI components to state management and performance.
- Build and maintain Python back-end services and APIs (FastAPI, Django or Flask), including data models on PostgreSQL.
- Take ownership of production systems: testing, CI/CD, monitoring and on-call for the services you build.
- Review code, mentor other engineers and raise the quality bar of the team.
- Work with product and design to turn loosely defined problems into clear technical plans.

## Requirements
- 5+ years of professional software engineering experience.
- 3+ years building production front ends with React; solid TypeScript.
- 3+ years building production back ends in Python.
- Experience with relational databases, REST or GraphQL API design, and cloud deployment (AWS, GCP or similar).
- Evidence of ownership: features or systems you led from design to production.
- Clear written and verbal communication in English.

## Nice to have
- Experience scaling web applications or improving front-end performance.
- Docker and Kubernetes, infrastructure as code.
- Open-source contributions.
